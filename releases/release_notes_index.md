## **📈 Roadmap Preview (v0.6)**

The next scheduled release (**v0.6**) will focus on:

* **Real-time FIDS (Flight Information Display System):** Utilizing Django Channels and WebSockets.  
* **Conflict Detection:** Proactive alerting for overlapping gate assignments.  
* **SSIM Import:** Native parsing of IATA Standard Schedules Information Manual files.
