# **Release Note v0.2: Aviation Data & Airport Infrastructure**

Release Date: 22-11-2025
Status: Released  
Codename: "Tarmac"

## **📋 Executive Summary**

Release v0.2 expands the system's scope from generic aviation data to specific **Airport Infrastructure Management**. This release introduces the "Digital Twin" capability, allowing operators to model physical airport assets (Terminals, Gates, Stands) and connect them with operational entities (Ground Handlers, Routes). It also introduces the first iteration of the Executive Dashboard.

## **🚀 Key Features**

### **1\. Airport Infrastructure Modeling**

* **Physical Asset Management:** New models and management interfaces for:  
  * **Terminals:** Definition of terminal codes and capacities.  
  * **Gates & Stands:** Configuration of boarding gates and parking positions with constraints (e.g., max wingspan).  
  * **Check-in Counters & Carousels:** Resource inventory management.  
  * **Runways:** Technical specifications for runway surfaces and dimensions.  
* **Infrastructure Seeding:** New seed\_airport\_infrastructure command to auto-generate a medium-sized airport layout (T1, T2, Domestic) for testing and demos.

### **2\. Enhanced Master Data**

* **Route Network:** Management of Airline Routes (Origin-Destination pairs) with equipment types and codeshare status.  
* **Ground Handling:** Database of Ground Handling Agents (GHAs) linked to Airlines, enabling service capability tracking (Ramp, Passenger, Cargo).  
* **Airport Reference Data:** Global airport database management with IATA/ICAO validation.

### **3\. Operational Dashboard v1**

* **Infrastructure Overview:** Real-time counters for active Terminals, Gates, and Stands.  
* **Utilization Metrics:** Introduction of "Gate Usage" and "Passenger Throughput" visualizations.

## **🛠 Technical Enhancements**

* **Search Functionality:** Global search implementation across all Master Data list views.  
* **Frontend Optimization:** Refactoring of terminal list cards and login page responsiveness.  
* **Docker Security:** Removal of sensitive database credentials from docker-compose snippets.

## **🗄️ Database Changes**

* Added models: Airport, Runway, Route, GroundHandler.  
* Added relations: Airline → GroundHandler (ForeignKey).  
* Updated Gate model to include infrastructure constraints.
