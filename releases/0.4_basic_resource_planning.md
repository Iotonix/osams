# **Release Note v0.4: Resource Allocation & Visualization**

Release Date: 06-12-2026 Status: Released  
Codename: "Allocation"

## **📋 Executive Summary**

Release v0.4 introduces **Intelligent Resource Management**, aiming to automate the complex task of assigning airport resources (Gates, Stands, Carousels). This release delivers the industry-standard "Pre-Allocation Strategy," ensuring 80% of flights are auto-assigned based on physical constraints, and provides a visual timeline for conflict detection.

## **🚀 Key Features**

### **1\. Automated Resource Allocation**

* **Constraint-Based Logic:** New allocate\_seasonal\_resources command that assigns resources based on:  
  * **Hard Constraints:** Aircraft Wingspan vs. Gate Max Width, Aircraft Type Compatibility.  
  * **Soft Constraints:** Terminal alignment (Domestic vs. International).  
* **Gate-Stand Linking:** Implementation of 1:1 binding between Contact Gates and Parking Stands, automating downstream resource blocking.  
* **Round-Robin Algorithm:** Intelligent distribution of flights across available gates to balance terminal utilization.

### **2\. Visual Gantt Chart (Vis.js Integration)**

* **Timeline View:** Interactive Gantt chart visualizing flight occupation across Terminals, Gates, and Check-in Rows.  
* **Status Color Coding:** Visual distinction between Scheduled (Blue), Active (Green), and Cancelled (Red) flights.  
* **Hierarchical Grouping:** Nested visualization of Terminal \-\> Gate \-\> Stand structures.

### **3\. Resource "Digital Twin" Enhancement**

* **Seasonal Preferences:** Added preferred\_gate, preferred\_stand, and preferred\_carousel to Seasonal Flight templates.  
* **Validation Layer:** Strong validation in SeasonalFlight.clean() to prevent physically impossible assignments (e.g., A380 on a Code C gate).

## **🛠 Technical Enhancements**

* **API Endpoints:** New internal API api/timeline-data/ providing JSON data for the frontend visualization.  
* **Management Commands:** Added link\_gates\_to\_stands utility for bulk infrastructure updates.

## **🗄️ Database Changes**

* Migration schedules.0002: Added preferred resource FKs to SeasonalFlight.  
* Migration masterdata.0007: Added stand ForeignKey to Gate.
