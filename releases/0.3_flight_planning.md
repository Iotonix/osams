# **Release Note v0.3: Flight Planning & Operations Engine**

Release Date: 29-11-2025  
Status: Released  
Codename: "Rotation"

## **📋 Executive Summary**

This release marks a critical milestone: the transition from static data to **Dynamic Operations**. v0.3 introduces the **Schedules** and **Flight Operations** applications, implementing the sophisticated "Rolling Window Strategy" for flight generation. This engine allows OS-AMS to function as a true operational planning tool, bridging the gap between seasonal schedules and daily execution.

## **🚀 Key Features**

### **1\. Schedule Management (schedules app)**

* **Seasonal Flights:** Creation of recurring flight templates (e.g., "Every Monday/Wednesday") valid for specific seasons (Summer/Winter).  
* **Advanced Seeding:** seed\_seasonal\_flights command using statistical frequency distribution (Daily 40%, Weekdays 30%) to generate realistic traffic patterns based on active Routes.

### **2\. Daily Operations Engine (flight\_ops app)**

* **Rolling Window Strategy:** Automated generation of DailyFlight records 90 days into the future.  
* **Smart Propagation:** Logic to propagate changes from Seasonal Schedules to Daily Flights while respecting manual overrides.  
* **Manual Override Protection:** Introduction of the is\_manually\_modified flag to protect operational decisions from being overwritten by automated processes.

### **3\. Operational Performance**

* **Performance Optimization:** Implementation of django-select2 for AJAX-based autocomplete on large dropdowns (Airlines, Airports), reducing form load times by \~80%.  
* **Date Navigation:** Seamless previous/next day navigation in the Daily Flight list view.

## **🛠 Technical Enhancements**

* **Refactored Admin:** Optimized fieldsets for DailyFlight to support operational workflows.  
* **Documentation:** Added PERFORMANCE.md and ROLLING\_WINDOW.md detailing architectural decisions.

## **🗄️ Database Changes**

* New App: schedules (SeasonalFlight model).  
* New App: flight\_ops (DailyFlight model).  
* Added Fields: is\_manually\_modified, schedule\_version, last\_propagated\_at to DailyFlight.
